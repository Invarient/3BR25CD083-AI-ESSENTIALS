 # 🤖 AI Essentials

A curated collection of fundamental scripts, notebooks, and production-ready boilerplate for core **Artificial Intelligence** and **Machine Learning** workflows. This repository serves as a practical, self-paced toolkit for building AI-driven systems.

## ✨ Key Features

* **Core ML Foundations:** Step-by-step implementations of basic classification, regression, and data preprocessing pipelines.
* **Deep Learning Blocks:** Essential PyTorch and TensorFlow setups for neural networks.
* **LLM & Prompt Engineering:** Clean templates for interacting with modern APIs (OpenAI, Anthropic) and managing prompt context.
* **AI Agents:** Lightweight, zero-fluff examples of autonomous tool-use and agentic reasoning.
